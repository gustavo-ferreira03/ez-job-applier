# Product

## Register

product

## Users

Job seekers who run repeated LinkedIn searches, review discovered roles, answer application questions, and monitor automated submissions from a desktop dashboard. They need to move quickly without losing control over which jobs are submitted, skipped, or held for review.

## Product Purpose

EZJobApplier manages automated job discovery and application workflows. It turns search criteria, resumes, provider state, and application status into one operational workspace where the user can start execution, resolve required input, review applications, and audit past runs.

## Brand Personality

Focused, sharp, calm. The interface should feel like a reliable control room for a high-stakes personal workflow: compact, legible, precise, and never noisy.

## Anti-references

Avoid generic SaaS-dashboard gloss, decorative gradients, oversized hero-style metrics, visual noise, soft novelty illustrations, and bright motivational styling that competes with job data or execution state.

## Design Principles

1. Preserve control: make automation state, pending decisions, and destructive actions obvious before the user commits.
2. Prioritize scan speed: keep job title, company, status, and required action easy to compare across dense views.
3. Use restraint for trust: accent color should signal action or state, not decorate every surface.
4. Keep density humane: support high information volume while preserving readable spacing, target sizes, and clear focus states.
5. Explain consequences: labels and empty states should say what will happen next, especially around execution, review, rejection, and submission.

## Accessibility & Inclusion

Target WCAG AA contrast and keyboard operability. Support reduced motion, visible focus states, non-color status cues where possible, readable placeholder text, and layouts that remain usable on smaller screens without clipping critical controls.
